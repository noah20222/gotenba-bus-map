
# 御殿場・小山地区 バス運行状況マップ

富士急バスのGTFSデータを利用した、
時間帯別・路線別の運行状況可視化サイトです。

## ファイル

- index.html : Webサイト本体
- data.json : GTFS集計データ

## GitHub Pages

1. GitHubリポジトリを作成
2. index.html と data.json をアップロード
3. Settings → Pages
4. Deploy from a branch
5. main / root を選択
6. 公開URLにアクセス

## 注意事項

- 運行本数は時刻表上の計画値です。
- 停留所間は直線で表示しています。
- 実際の道路経路を示すものではありません。
- 平日・土曜・日曜は代表日による集計です。
- 時間帯をまたぐ運行区間は複数時間帯に計上されます。
- 停留所別の本数は時刻表上の発車イベントに基づきます。
- GTFSの利用条件・出典表記を確認して公開してください。
